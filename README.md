# Numerical Methods

This repository contains C++ implementations and Jupyter notebooks for various numerical methods, organized by topic. It is intended for students and practitioners of numerical analysis, scientific computing, and engineering.

## Folder Structure

- **eq.cpp, myRK4.cpp, NML_Lab5.cpp, Numerical_Assignment_main.cpp, task.cpp**: Standalone C++ source files for different numerical methods and assignments.
- **1.Linear-Equations/**: Methods for solving systems of linear equations (e.g., Gaussian elimination, LU decomposition).
- **2.Non-linear-Equations/**: Methods for solving non-linear equations, including:
  - Bisection Method
  - False Position Method
  - Newton-Raphson Method
  - Secant Method
  - Custom solutions in `myNON-linear-solns.cpp`
- **3.ODE/**: Methods for solving ordinary differential equations (ODEs), such as Runge-Kutta and inversion techniques.
- **4.InterpolationMethods/**: Interpolation, curve fitting, numerical differentiation, and integration methods. Includes both C++ and Jupyter notebook implementations.
- **NLMlabtest/**: Additional C++ files and notebooks for lab tests and practice, covering curve fitting, differentiation, integration, and non-linear equation solvers.
- **taskopenendedB@2/**: Contains open-ended tasks and related notebooks.

## How to Use

1. **C++ Files**: Compile using a C++ compiler (e.g., `g++ filename.cpp -o output.exe`).
2. **Jupyter Notebooks**: Open `.ipynb` files with Jupyter Notebook or VS Code.
3. **Explore by Topic**: Each folder is organized by numerical method type for easy navigation.

## Requirements
- C++ compiler (e.g., GCC, MinGW, or MSVC)
- [Jupyter Notebook](https://jupyter.org/) (for `.ipynb` files)
